# Plan: Mobile UI/UX view

Date: 2026-09-28
State: proposed — not yet implemented

## Problem

The app renders on phones as a zoomed-out desktop page:

1. **No viewport meta** — `src/app/layout.tsx` exports only `metadata`; mobile
   browsers fall back to a ~980px virtual viewport.
2. **Chat sidebar is always open** — `chat-client.tsx` uses a fixed
   `width: 240` `<aside>` inside `display: flex; height: 100vh`; on a 390px
   phone the sidebar eats most of the screen with no way to collapse it.
3. **Fixed-width grids in the portal payment panel** —
   `gridTemplateColumns: "180px 1fr"` rows (amount / equivalent) overflow on
   narrow screens; QR (240px) + address share one row and crush the address.
4. **`globals.css` has zero media queries** — no breakpoint system exists.
5. Landing page uses fixed 40px title / 80px paddings that waste mobile space.

## Dependency verification

No new external dependencies are proposed. The work is CSS + existing React
state — `jev-scout` verification is therefore not applicable to any task below.
(Deliberately avoiding a component-test library; tests use the installed
`vitest` reading source, plus `next build` as the integration gate.)

## Approach

CSS-first, mobile-last media queries at **768px** (layout) and **560px**
(content rows). Desktop rendering stays byte-for-byte the same behavior;
mobile gets an off-canvas chat sidebar and stacked portal rows. Inline styles
that are breakpoint-dependent move to named CSS classes in `globals.css`.

## Tasks

### Task 1 — Viewport export (TDD Red/Green)

Files: `src/app/layout.tsx`, `tests/mobile-ui.test.ts`

1. **Red**: create `tests/mobile-ui.test.ts` reading `src/app/layout.tsx` and
   asserting it contains `export const viewport` with
   `width: "device-width"` and `initialScale: 1`. Run `npm test` — expect
   1 failure.
2. **Green**: in `layout.tsx` add (per `generate-viewport.md`):
   ```tsx
   import type { Viewport } from "next";
   export const viewport: Viewport = { width: "device-width", initialScale: 1 };
   ```
3. Run `npm test` — expect 0 failures.
4. Commit: `feat: add mobile viewport meta`.

### Task 2 — CSS breakpoints foundation

Files: `src/app/globals.css`, `tests/mobile-ui.test.ts`

1. **Red**: extend the test to assert `globals.css` contains
   `@media (max-width: 768px)` and `@media (max-width: 560px)` blocks. Expect
   failure.
2. **Green**: add:
   - `@media (max-width: 768px)`: smaller page paddings; landing `h1` 28px.
   - `@media (max-width: 560px)`: `.pay-row` and `.amount-row` become single
     column (`grid-template-columns: 1fr`); `.pay-flex` stacks vertical;
     purchases table cells padded tighter.
   - Chat off-canvas classes: `.chat-shell`, `.chat-sidebar`,
     `.chat-backdrop`, `.sidebar-open` (transform/translateX, fixed
     positioning under 768px only — desktop layout untouched).
3. Run `npm test` — expect 0 failures. Commit: `feat: mobile breakpoint styles`.

### Task 3 — Chat off-canvas sidebar

Files: `src/app/chat/chat-client.tsx`

1. Replace shell/aside inline layout classes with `.chat-shell` /
   `.chat-sidebar`; add `sidebarOpen` state (default false).
2. Under 768px: hamburger button in the chat column toggles the sidebar;
   backdrop click closes it. Desktop (>768px): sidebar always visible, toggle
   hidden (pure CSS, state harmless).
3. **Verify Red/Green**: `npx tsc --noEmit` passes; `npm run build` passes.
4. Commit: `feat: mobile off-canvas chat sidebar`.

### Task 4 — Portal responsive payment panel

Files: `src/app/portal/portal-client.tsx`

1. Move breakpoint-dependent inline styles to classes: `.pay-flex` (QR +
   address row), `.amount-row` (the two `180px 1fr` grids), `.purchases`
   (table → tighter rows on mobile).
2. On ≤560px: QR above address, address input full width, amount rows stack.
3. Verify: `npx tsc --noEmit` + `npm run build`. Commit:
   `feat: responsive portal payment panel`.

### Task 5 — Landing page mobile + final gate

Files: `src/app/page.tsx`

1. Reduce fixed paddings (`80px 24px` → class `.landing` with responsive
   padding), title size via media query.
2. **Verify Green**: `npm test` (all pass), `npm run build` (0 errors).
3. Commit: `feat: mobile-responsive landing page`.

## Validation (whole feature)

- `npm test` — 0 failures
- `npx tsc --noEmit` — clean
- `npm run build` — compiles
- Manual: `npm run dev`, resize 390×844 — chat sidebar collapses/expands,
  portal payment rows stack, no horizontal scroll.

## Risks

- Inline-style → class migration in portal could silently change desktop
  spacing; mitigated by only moving rules referenced by media queries and
  keeping identical desktop values.
- Chat sidebar fixed positioning must not cover the composer's safe-area on
  iOS (padding from env(safe-area-inset-bottom) if needed).
